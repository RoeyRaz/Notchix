Windows 11 desktop companion

A little more life at the top of your screen.

Notchix brings your music, useful glances and quick tools into a compact island that stays out of the way. Built in Rust with native Windows drawing.

Get the latest releaseRead the setup guideView source

An independently branded derivative of Nock by Akhilesh Varute. The original MIT license and attribution are retained.

♫

Music stays close

See the current track, control playback and use the optional Spotify queue connection.

◌

Tools within reach

Calendar, activity, clipboard, shelf, quick settings and a local CSV/TSV data profile.

✧

Your desktop stays yours

Glass styling is optional. Explorer keeps control of the Windows taskbar; there is no game FPS overlay.

Windows 11 is the primary release target. Notchix also retains a smaller Linux preview, which receives less testing. Integrations such as calendar feeds, qBittorrent and Spotify are optional and explained in the setup guide.
