# Taskbar direction

Notchix 1.0 leaves Windows Explorer in control. The previous partial-width
replacement was removed because it did not meet the intended quality bar and
hid Windows features users rely on.

If taskbar replacement is reconsidered later, first define full requirements:
window grouping and previews, pinned apps, system tray and overflow, quick
settings, notifications, work-area reservation, multiple displays, full-screen
handoff, crash recovery and an immediate way to restore Explorer. Profile idle
CPU/RAM and frame pacing on Windows 11 before distribution. A visual dock is
not equivalent to a taskbar and should not be represented as one.
