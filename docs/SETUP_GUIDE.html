Make the notch yours.

A quick, calm setup for Notchix on Windows.

01 · FIRST RUN

Start with the essentials

  1. Launch Notchix from Start. Click the top island to open it.
  2. Right-click the tray icon for glass, startup, alerts and clock preferences.
  3. Use the icon rail to move between Media, Activity, Agenda and Tools.
02 · MEDIA

Spotify controls and queue

Play, pause, artwork and volume use Windows media controls automatically. To search and add tracks directly to Spotify, follow the Spotify queue guide.

Queue search uses Spotify PKCE sign-in. Create a Client ID only; never create or paste a Client Secret. Premium and an active playback device are required by Spotify.

03 · AGENDA

Connect a calendar

Open Agenda and use its calendar connection controls. A private read-only ICS feed can be used when supported by your provider. Keep the feed URL private; it can grant access to event details.

Calendar display depends on the details and time zone supplied by your calendar feed.

04 · TRANSFERS

Show real torrent progress

Follow the qBittorrent setup guide. Bind the Web UI to localhost, keep authentication enabled and do not forward its port to the internet.

Progress and ETA only appear when qBittorrent supplies those values.

05 · OPTIONAL

Notion task capture

Run SETUP-NOTION.ps1 from the installed docs folder. Share the intended database with your integration. Its token is protected for the current Windows account with DPAPI.

Notion is optional; no task is sent until you choose its save action.

06 · LOCAL

CSV / TSV quick profile

Tools → CSV quick profile reads a UTF-8 table on this PC and summarizes rows, columns, empty cells and numeric ranges. Limit: 32 MB, 250,000 rows and 128 columns.

The selected file is not copied or uploaded. Use a full statistical tool for deeper analysis.

GOOD TO KNOW

Windows taskbar, FPS, privacy and credit

Notchix does not replace Windows’ taskbar and does not display an in-game FPS overlay. If an older preview hid the Windows taskbar, launch this build once to restore the saved Windows auto-hide state.

Settings remain under %APPDATA%\Nock for compatibility. Notchix is a distinct derivative based on Nock by Akhilesh Varute; the included MIT license retains the original attribution.

For changes and support, visit Notchix on GitHub.
