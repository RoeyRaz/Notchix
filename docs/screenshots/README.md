# Notchix screenshots

These PNGs are deterministic renders from the current Notchix UI code, not captures of a user's desktop. The track, cover art, lyrics, system state and notifications are illustrative test data; they do not demonstrate a live Spotify session, Windows notification permission, or measured system values.

The screenshot fixture lives in `src/app.rs` under `preview::render_pages`. The pastel cover image is a locally generated gradient used only by that fixture.
